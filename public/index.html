实验人员预先摆好部分离心管时，按「管编号 + 孔位」登记固定孔位，整组保存 / 修改 / 清空； 未知管、重复管或孔、越界孔、不在该管可用孔位内的绑定将被整组拒绝（原绑定保留）。 修改管的可用孔位或转子孔数使绑定失效时同样整次拒绝。 装载图必须将指定管放在固定孔位，并同时满足承重、对径差与避邻规则； 清空固定孔位后，流程与无固定孔位完全一致。

10. 配重块临时停用

按质量规格登记停用数量、原因与 UTC 起止时间，时段按 左闭右开 [开始, 结束) 计算；同规格重叠停用量累加，任一时刻不得超过登记时 该规格的当前库存。停用立即影响新预约：预约时同时核对库存、生效停用与已有预约， 占用加停用超库存则整单拒绝。停用可与既有预约重叠，既有预约不改写。 仅未开始的停用可撤销，撤销留历史并释放后续容量。

停用记录（含已撤销历史）

11. 离心运行

以唯一运行编号 + 非空设备编号 + 已完成核验编号 + 预约编号开始一次离心运行； 开始/结束时间由服务端记录。开始时在事务内确认：核验已通过、核验与生效预约指向 同一张发布图、发布图当前可用、当前时刻处于预约 左闭右开 [开始, 结束) 时段、该预约未被其他运行使用、同设备无进行中运行、 保养额度未达上限；已有校准记录的设备还须最新校准合格且到期不早于预约终点 （无校准记录的设备沿用原规则）； 任一冲突即拒绝且不留记录。开始后冻结发布图、核验结论、预约时段与校准依据；完结如实填写 「完成 / 中止」，超过预约终点完结会标记超时，随即释放设备，不改写预约与校准依据。 相同运行编号同内容重复提交返回原记录，异内容拒绝；完结同状态重放返回原结果。

运行列表（含运行状态、超时标记与冻结依据）

12. 设备校准（放行依据）

实验室按设备校准记录决定运行能否放行。登记时填写唯一校准单号、设备编号、 校准时间、到期时间与合格/不合格结论（时间均为 UTC）：校准时间须早于到期时间、 不得晚于服务端当前时刻，同设备校准时间须晚于上一条。记录只追加，按 最新一条判定。已有校准记录的设备开始运行时，须最新结论合格且到期时间 不早于本次预约终点；无校准记录的设备沿用原开始规则。开始成功后冻结校准依据， 之后新增记录、运行超时或完结不改写历史。同号同内容重放返回原记录，异内容拒绝。

校准记录（按校准时间倒序，只追加）

13. 设备保养（按累计运行时长）

按设备编号设置正整数秒数的保养上限：系统统计自最近一次保养后已完结运行的 累计时长（完成 / 中止均按服务端起止时间计入，进行中不提前计入；尚无保养记录时计入 全部已完结运行），并给出剩余额度与待保养状态。运行即使越过上限也如实完结并释放设备； 达到上限后新的运行将被拒绝（未设置上限的设备不核对，沿用原行为）。 设备空闲时可凭唯一保养单号 + 设备编号 + 原因登记保养并开启新累计周期； 同号同内容重试返回原记录，异内容或设备运行中拒绝。调整上限仅影响后续开始判定， 不改写运行及保养历史。
